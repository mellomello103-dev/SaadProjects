                                    # User Authentication & Profile Management System 🐍🔐

نظام متكامل ومؤمن لإدارة حسابات المستخدمين والملفات الشخصية، مبني باستخدام إطار العمل **Django**. يوفر النظام العمليات الأساسية لتسجيل الحسابات والتحقق من الهوية بشكل آمن.

## 🚀 المميزات الرئيسية (Features)
*   **تسجيل مستخدم جديد (User Registration):** واجهة مجهزة تتيح للمستخدمين الجدد إنشاء حسابات والتحقق من البيانات.
*   **تسجيل الدخول والخروج (Login / Logout):** نظام حماية مدمج للتحقق من هوية المستخدمين وإدارة الجلسات (Sessions).
*   **إدارة الملف الشخصي (Profile Management):** إنشاء ملف شخصي تلقائي لكل مستخدم يربط بياناته الأساسية ويسمح بتوسيعها مستقبلاً.
  
---

## 🛠️ التقنيات المستخدمة (Tech Stack)
*   **Back-End Framework:** Django (Python 3.13)
*   **Front-End:** HTML5, CSS3 (قوالب مخصصة داخل التطبيق)
*   **Database:** SQLite (قاعدة بيانات خفيفة ومدمجة ومرفقة مع المشروع كملف `db.sqlite3`)

---

## 📁 الهيكل البرمجي للمشروع (Project Structure)
*   `myFirstproject/`: المجلد الرئيسي للمشروع ويحتوي على ملف الإدارة `manage.py`.
*   `myFirstproject/myFirstproject/`: يحتوي على الإعدادات العامة للموقع والمسارات الرئيسية (`settings.py`, `urls.py`).
*   `myFirstproject/Myfirstapp/`: التطبيق الفرعي (App) المسؤول عن منطق الحسابات ويحتوي على الكود البرمجي للنماذج والواجهات (`models.py`, `views.py`, `urls.py`).
*   `myFirstproject/Myfirstapp/templates/`: يحتوي على واجهات العرض الخاصة بالمستخدم (`Register.html`, `login.html`, `home.html`).

## ⚙️ طريقة التشغيل والتهيئة (Setup & Running)

### 1. تثبيت إطار العمل Django
قم بفتح واجهة الأوامر (Terminal) في مجلد المشروع الرئيسي وثبت مكتبة Django:
```bash
pip install django
```

### 2. تحديث وتطبيق قاعدة البيانات
بما أن ملف قاعدة البيانات جاهز مسبقاً ومرفق (`db.sqlite3`)، يمكنك التأكد من مطابقة الجداول عبر تشغيل أمر الهجرات:
```bash
python manage.py migrate
```

### 3. تشغيل الخادم المحلي (Development Server)
لتشغيل موقع الويب محلياً على جهازك، اكتب الأمر التالي:
```bash
python manage.py runserver
```

بعد تشغيل الأمر، سيظهر لك رابط محلي بالمتصفح، قم بفتحه (غالباً ما يكون):
`http://127.0.0`
